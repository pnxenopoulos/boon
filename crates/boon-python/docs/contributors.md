# 🤝 Contributors

Boon improves when users report bugs, test demos, and propose changes.
Thanks to everyone who helps the project. The entries below recognize
specific community contributions.

## ghaif

Thanks to [ghaif](https://github.com/ghaif) for identifying and investigating
four changes included in Boon 0.8.0. Their reports, examples, and initial work
helped guide the final changes:

- [PR #38](https://github.com/pnxenopoulos/boon/pull/38) — Sinner's
  Sacrifice machine events
- [PR #37](https://github.com/pnxenopoulos/boon/pull/37) — breakable map prop
  events
- [PR #35](https://github.com/pnxenopoulos/boon/pull/35) — melee damage
  detection
- [PR #34](https://github.com/pnxenopoulos/boon/pull/34) — cross-build
  `EModifierValue` renumbering

These pull requests were not merged directly but their findings helped guide the
final implementations.
